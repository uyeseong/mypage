MY 3 YEAR PLAN

꿈을 향해 끊임없이 성장하는 개발자 로드맵 (집중 · 반복 · 공유)

비전

사람들에게 실질적인 가치를 주는 소프트웨어를 만들고, 팀과 함께 성장하는 개발자가 된다.

핵심 가치

  • 사용자 중심: 기능보다 문제 해결과 경험을 우선한다.
  • 꾸준함: 매일 작은 진전을 쌓아 복리효과를 만든다.
  • 공유와 협업: 기록하고 나누며 더 빠르게 배운다.

관심 분야

웹 백엔드 클라우드 분산 시스템 DevOps 개발 생산성

존경하는 인물

꾸준히 배우고, 사용자 문제를 집요하게 해결하는 개발자들.

3개년 로드맵

Year 1: 기초 탄탄히

  • 자료구조/알고리즘 주 3회 문제풀이(기본/투포인터/DP)
  • CS 필수(운영체제, 네트워크, DB) 요약 노트 정리
  • 백엔드 기본 스택 한 줄: Java/Spring 또는 Node/Nest
  • 팀 프로젝트 1개(요구사항→설계→배포 전 과정 경험)
  • 블로그 주 1회 기록, Git 커밋 데일리 스트릭

Year 2: 실전 역량 강화

  • 클라우드 기초(AWS EC2, S3, RDS) + CI/CD 구축
  • 테스트 주도 개발 습관화
  • 성능/캐시/스케일링 실험
  • 오픈소스 PR 2건 이상
  • 운영 서비스 1개

Year 3: 전문성·취업

  • 분산 시스템 심화 (Kafka, 이벤트 소싱 등)
  • 테크 블로그 + 발표
  • 시스템 디자인 20세트
  • 이력서/포트폴리오 최적화
  • 취업 후 온보딩 전략
